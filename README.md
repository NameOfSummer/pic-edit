# pic-edit

ブラウザで動く画像編集アプリです。最初の版では、Shottr のように画面全体を透過の市松模様（チェッカーボード）にし、画像をドラッグ＆ドロップまたはペーストで配置できます。

## できること

- 画面背景に透過を示す市松模様を表示
- 画像ファイルのドラッグ＆ドロップ
- クリップボードからの貼り付け（`⌘V` / `Ctrl+V`）
- 配置した画像の移動・右下ハンドルでのリサイズ
- 選択中画像の削除（Delete / Backspace）

PNG など透過つき画像は、透明部分から市松模様が見えます。

## 起動

```bash
npm install
npm run dev
```

ブラウザで表示された URL を開いてください。
